# LDTS_T03_G05 - Claw Crawler

## Game Description

Claw Crawler is a dungeon-crawler game based on traditional fantasy tropes. The gameplay sees the player character
navigating a series of maze-like environments while climbing down a dungeon and fighting several enemies.
Throughout the levels the player levels up and gains new abilities.

This project was developed by Bernardo Barbosa (up202403438@edu.fe.up.pt), João Fardilha (up202403383@edu.fe.up.pt) and
Pedro Santos (up202405319@edu.fe.up.pt)
